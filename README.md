The app: Pallete me
- What is it about:
Palette Me is a personalized design app that allows users to create their own color themes. Users can can enter a name for their design, and choose four colors to customize different parts of the app itself.
The app also includes a personal design library, where users can save and switch between their past created designs.
- Core features:
Custom Designs: Create personalized designs using four colors.
Design Names: Give each design a name.
My Designs: Save multiple designs in a personal list.
Switch Between Designs: Click on a saved design to load it again.
Color Customization: Customize backgrounds, titles, text boxes, and buttons.
- Dependencies:
The project uses Python and the Flet library.
How to run the app:
Make sure that Python and Flet are already installed.
Run the app on your computer.
Enter a name and colors for your choice (in small letters), you can also enter a specific shade with its code.
Press the create button.
Now you can create more designs and switch between them.
